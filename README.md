# SparkFlow Animated Landing Page

A modern startup landing page created using HTML, CSS, and JavaScript.

## Features

- Responsive startup landing page
- CSS hover transitions
- Keyframe animations
- Floating hero animation
- Scroll reveal animation using Intersection Observer API

## Animation Decisions

Animations were added to improve user experience and highlight important sections.

The hero animation creates an engaging first impression without distracting users.

Hover effects on buttons and cards provide visual feedback during interaction.

Scroll reveal animations were used only for the features section to keep the design clean and professional.
