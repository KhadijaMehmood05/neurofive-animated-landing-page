# SparkFlow - Animated Landing Page 🚀

A modern and responsive startup landing page created using **HTML, CSS, and JavaScript**.  
This project demonstrates the use of animations, transitions, and scroll-based effects to create a smooth and engaging user experience.

## 🌐 Project Overview

SparkFlow is a fictional productivity platform designed to help teams manage projects, collaborate efficiently, and improve workflow. The landing page focuses on creating a professional startup-style design with interactive animations and modern UI elements.

## ✨ Features

- Responsive single-page startup landing page
- Modern hero section with animated elements
- Navigation bar with smooth scrolling
- Trusted companies section
- About section
- Feature cards section
- Statistics/impact section
- Customer testimonials section
- Call-to-action section
- Footer section

## 🎨 Animation & Transition Features

- CSS hover transitions for buttons
- CSS hover effects for feature cards
- Floating animation for hero elements using `@keyframes`
- Fade-in entrance animations
- Smooth card reveal animations
- Scroll-triggered animations using JavaScript Intersection Observer API

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript
- Intersection Observer API

## 🎬 Animation Decisions

Animations were added to improve user experience and highlight important sections of the landing page without overwhelming the user. I used hero animations to create an engaging first impression, while hover effects on buttons and cards provide clear feedback during interaction. The scroll reveal animation was added only to the features section because revealing content gradually helps maintain user attention. I avoided excessive animations throughout the page to keep the design professional, smooth, and easy to navigate.
